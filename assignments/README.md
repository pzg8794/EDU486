## Status Rule

An artifact is complete when its reviewed source or intended export exists.
Submission is verified only through Blackboard, Sent mail, or direct recipient
evidence. The [closeout record](../docs/course-closeout.md) keeps these states
separate. The final Plastic Pirates youth-photo poster was produced and printed
but remains in protected local storage rather than this public repository.

## Completion Standard

Each assignment should include:

- the actual requirement it answers
- a personalized draft
- source/framework links
- accessibility and equity notes
- AI-use disclosure when applicable
- revision notes after feedback
- explicit attention to bodymind access, language access, identity safety, and rigorous multiple pathways for evidence
